01

Prepare the source material

Choose a format with clear question boundaries and an identifiable answer key. JSON, CSV, plain text, and Markdown are the documented first-phase formats.

  • Keep the original question wording and language.
  • Keep each answer choice in its original order.
  • Include the authoritative answer key and any rationale/explanation.
  • Note the source, subject, topic, tags, difficulty, and image references if available.
  • For local images, keep the image files alongside your working materials; a JSON path does not embed the image itself.
Source gap? If the answer key or rationale is missing, keep that record flagged for review. Do not ask the converter to guess.

02

Give the AI the conversion instructions

Open SKILL.md and provide it to an AI assistant that can access your source content. Attach or paste the source in a format that the chosen environment can actually read.

Suggested task brief
Use the StudyMats Test Bank Converter instructions in SKILL.md to convert the supplied source into a valid UTF-8 JSON array compatible with the StudyMats Question Authoring Studio.

Preserve wording, language, choice order, answer keys, rationales, references, image references, tags, and compatible metadata. Never invent missing answers or explanations.

Report warnings, invalid/skipped records, duplicate IDs, possible duplicate stems, and any transformed or lost fields. Include a reconciled conversion summary and a human-readable review list.

The brief is a starting point. Tell the assistant the specific source format and any known answer-key conventions.

03

Convert conservatively

Ask the assistant to emit a JSON array of question objects, plus a separate human-readable report. The output should follow the canonical schema rather than rewriting the underlying educational content.

questionNon-empty stem
options2+ distinct choices
correctAnswerZero-based integer
rationaleText + images array

In correctAnswer, the first option is index 0, the second is 1, and so on. Do not confuse a source label such as “B” with a numeric index until the choices have been mapped in their original order.

04

Validate the JSON and reconcile counts

Before importing, check that the output parses as JSON and that each importable question contains the required fields. A valid JSON file can still contain an incorrect answer key, so review content as well as syntax.

  • Top-level output is a JSON array.
  • Every record has a non-empty question and unique ID.
  • Options contain at least two distinct, non-empty strings.
  • correctAnswer is an integer within the options array.
  • rationale.text is non-empty and rationale.images is an array.
  • Image paths, citations, references, tags, and metadata are preserved or explained.
  • Counts for clean, warning, review-required, and skipped records are clearly defined and reconciled.
Important: A structurally valid file is not proof that its answers are factually correct. Compare answer keys and rationales with the source.

05

Review and import into StudyMats

  1. Open the StudyMats Question Authoring Studio in your application.
  2. Choose the JSON file you have reviewed.
  3. Select the destination subject when prompted.
  4. Inspect the import preview and all validation notes.
  5. Check sample questions, answer selections, rationales, and any images that matter.
  6. Confirm the import only after you are satisfied with the preview.

The import preview is the final practical check. If the preview differs from the source or a field is missing, stop and fix the JSON before confirming.

★

Troubleshooting common issues

Import says a required field is missing

Check that the question has a non-empty question, at least two distinct options, an in-range integer correctAnswer, and a rationale object with non-empty text and an images array.

The correct option appears wrong

Verify the original choice order and answer key mapping. correctAnswer is zero-based, so option B is normally index 1 when A is first and no options were reordered.

Images do not appear

Image paths and URLs are references, not embedded media. Ensure local assets are included and that the destination can resolve the paths. Report unresolved references rather than silently dropping them.

Some source questions were skipped

Review the conversion report and reconcile all source records. Records without a reliable answer key, rationale, or clear structure may need manual correction before they can be imported.
