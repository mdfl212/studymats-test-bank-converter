Conversion principles

Faithful first. Reviewable always.

✓

Preserve source meaning

Keep original wording, language, answer choice order, answer keys, rationales, citations, tags, and useful metadata.

✓

Never invent missing content

Missing answers or explanations are review items—not invitations to guess or fabricate.

✓

Report losses and uncertainty

Call out invalid records, duplicate IDs, possible duplicate stems, ambiguous keys, and unresolved image references.

✓

Validate before importing

Check the JSON structure, required fields, answer index, distinct options, and rationale before using the in-app preview.

Good to know

Frequently asked questions

Does this repository convert files automatically?

No. It contains an AI conversion skill, format guidance, examples, and validation cases. It is not a standalone web app or automatic parser.

Can I convert PDFs or Word documents?

They are not guaranteed by the first-phase specification. If your current AI environment cannot read the file reliably, export it to CSV, Markdown, plain text, or JSON and preserve image assets separately.

Will conversion upload my source file?

This repository itself does not upload files. The StudyMats browser import workflow is local, but how a source is handled during AI-assisted conversion depends on the AI tool and service you choose. Follow that service's privacy settings and policies.

Can I import the output immediately?

Review it first. Verify answer keys, rationales, warnings, and media paths, then use the Question Authoring Studio preview before confirming the import.
